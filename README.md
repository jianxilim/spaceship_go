# 🚀 星际小飞船 Spaceship Game

一个用纯 HTML + JavaScript（Canvas）写的竖版射击小游戏。不用安装，打开网页就能玩，电脑和手机都支持。

## 🎮 在线试玩

👉 **https://jianxilim.github.io/spaceship_game/**

## 🕹️ 操作方式

| 操作 | 电脑 | 手机 |
|------|------|------|
| 移动 | 方向键 / WASD | 手指按住屏幕拖动 |
| 射击 | 自动 | 自动 |
| 🛡️ 护盾 | J 或 Q | 右下角「护盾」按钮 |
| 💥 炸弹 | K 或 E | 右下角「炸弹」按钮 |
| 开始 / 重开 | 空格 或 回车 | 点按钮 |

## ✨ 技能与防御

| 技能 | 效果 | 冷却 |
|------|------|------|
| 🛡️ 护盾 | 4 秒内挡住所有子弹和撞击（快结束时会闪烁） | 10 秒 |
| 💥 炸弹 | 清除全屏敌方子弹，对所有敌人造成 3 点伤害 | 20 秒 |
| 💚 自动回血 | 5 秒没受伤后，每 8 秒回复 1 点生命 | — |

- 初始生命 5，最多 6
- 技能按钮发光表示可以使用，灰色遮罩显示冷却进度

## 👾 敌人

| 敌人 | 特点 | 分数 |
|------|------|------|
| 🪨 陨石 | 直线落下，2 下打碎 | +10 |
| 🔴 红色敌机 | 会开火，子弹基本直线往下（只稍微偏向玩家） | +30 |
| 🟣 紫色菱形 | 左右乱窜，速度快 | +20 |

存活越久，敌人越多、越快（每 30 秒升一级）。

## 🎁 道具

敌人被击落时有 20% 机会掉落：

- 🟡 **P**：火力升级（最多 3 发散射，持续 10 秒）
- 🟢 **+**：回复 1 点生命

最高分会自动保存在浏览器中。

## ⚙️ 调整难度

打开 `index.html`，找到「技能参数」这一段，改数字就行（游戏按每秒 60 帧计算，60 = 1 秒）：

```js
const SHIELD_TIME=240, SHIELD_CD=600;   // 护盾持续 4 秒，冷却 10 秒
const BOMB_CD=1200;                     // 炸弹冷却 20 秒
const REGEN_WAIT=300, REGEN_EVERY=480;  // 5 秒没受伤后，每 8 秒回 1 血
const MAX_HP=6;                         // 最大生命
```

## 🛠️ 技术

- 单个 `index.html` 文件，无任何依赖
- 所有图形用 Canvas 代码绘制，不需要图片或模型素材

## 📂 本地运行

下载 `index.html`，双击用浏览器打开即可。
